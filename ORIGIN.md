# Brainsmith: origin notes

Brainsmith is an original word game created by Smitty and published under **Padre Smitty Games**.
These notes record when and how it was made. The living copy, with the family story filled in, is
the "Brainsmith Origin Notes" doc; this file is the dated copy kept with the code.

## The game

Two to five players each pick a word in secret, and all the words are revealed at the same moment.
Each new round, every player picks one word that connects the words just revealed. The game ends
when every player says the same word ("Forged!"). Words can never be reused.

Example: Avocado and Tennessee, then Florida and Mexico, then everyone says Border.

## Name history

Called Samesies through October 12, 2026, and Brainsmith since. The name changed because
What Do You Meme, LLC holds a registered SAMESIES trademark for card games.
